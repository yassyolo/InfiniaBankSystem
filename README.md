Won 1st place in Experian Workshop 2024

Overview
InfiniaBankSystem is a comprehensive banking system developed to streamline banking operations and enhance customer experience.

Features
Account Management: InfiniaBankSystem allows customers to manage their bank accounts effortlessly, including checking balances, viewing transaction history, and transferring funds.
Loan Services: The system provides a streamlined process for applying for, approving, and managing loans.
Customer Support: Integrated AI-powered chatbots assist customers with their queries in real-time, enhancing customer service.
Security: Implements robust security measures, including two-factor authentication and fraud detection algorithms, to protect customer data and transactions.
Analytics and Reporting: Offers detailed analytics and reporting tools to help bank administrators make informed decisions.

Contents
Backend: Developed using C# to handle all business logic and database interactions.
Frontend: Built with HTML, CSS, and a small amount of JavaScript for a responsive user interface.
Database: Modeled and managed using SQL databases.
AI Models: Integrated various AI models to predict customer behavior and detect fraudulent activities.
Deployment: All components are deployed in Azure for scalability and reliability.
